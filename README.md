# 八字排盘（手机版 PWA）

一款可添加到手机桌面的八字排盘工具。按参考图还原输入页与排盘结果页，支持保存命例、逐个/批量删除、导出规整 Word 文档。纯前端运行，无需服务器，数据保存在本机浏览器。

## 功能

- **八字排盘**：公历转四柱（年月日时）、十神、地支藏干、藏干十神、十二长生、纳音、农历、星期、起运时间、八步大运。
- **滚轮日期选择**：年/月/日/时/分五列滚轮，支持公历与农历切换；农历自动列出闰月并正确换算天数，切换历法时保持同一天。滑动带提示音与震动反馈，底部可开关声音。
- **真太阳时**：可选地区（内置常用城市经度）或自定义东经，按 `(经度 − 120°) × 4 分钟` 校正。
- **命例管理**：排盘时自动保存、查看历史命例、逐个删除、勾选批量删除。
- **导出 Word**：单个或批量导出 `.docx`，含基本信息、四柱表格（含十神/藏干/长生/纳音）、大运表格，中文字体与表格样式规整。
- **备份迁移**：命例可导出 JSON 备份，并在另一台设备导入。
- **离线可用**：PWA + Service Worker，首次打开后离线也能排盘。

## 本地运行

需要用 HTTP 服务打开（PWA 在 `file://` 下无法注册 Service Worker）：

```bash
cd bazi-pwa
python -m http.server 8777
```

浏览器访问 `http://localhost:8777`。

## 部署到 GitHub Pages

1. 将本目录推送到 GitHub 仓库。
2. 仓库 → Settings → Pages → Build and deployment → Source 选择 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存。
3. 打开生成的 `https://<用户名>.github.io/<仓库名>/` 即可使用（HTTPS 是添加到桌面的前提）。

## 添加到手机桌面

**安卓（Chrome / Edge）**
打开网页 → 右上角菜单 → 「安装应用」或「添加到主屏幕」→ 确认。之后从桌面图标启动，全屏运行、可离线使用。

**iPhone / iPad（Safari）**
用 Safari 打开网页 → 底部「分享」按钮 → 向下找到「添加到主屏幕」→ 命名 → 添加。注意：必须用 Safari，且页面需为 HTTPS（GitHub Pages 满足）。

## 数据存储说明

命例保存在浏览器的 `localStorage`（键名 `bazi_pwa_cases_v1`），不会上传服务器。清除浏览器数据、更换手机或浏览器会导致命例丢失，建议定期用「命例 → 备份」导出 JSON 保存。

## 技术说明

- 八字算法：`lunar-javascript`（已本地化到 `lib/lunar.js`），采用节气换月、早子时/晚子时等规则；大运按男 1 / 女 0、1 派起运算法。
- Word 导出：前端使用 `JSZip` 生成标准 OOXML（`.docx`），直接在浏览器下载。
- 无构建步骤，无第三方运行时服务。
